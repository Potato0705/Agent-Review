# Agent 轨迹质量评分标准（0–10分）

评价这次 Agent 运行**解决任务的质量**，依据是整条轨迹，不只是最终答案。

## 评分维度

1. **结论正确与任务回应（0–3分）**：最终答案是否直接回应任务，结论是否成立。
2. **证据充分（0–4分）**：结论所依赖的事实，是否都由轨迹中某一步实际取得？每一条关键断言都应能指向一个具体步骤及其返回结果。
3. **过程有效（0–2分）**：步骤是否都对解决任务有贡献，是否存在重复、空转或与任务无关的调用。
4. **表述清楚（0–1分）**：答复是否易读、无歧义。

## 重要约束

- **结论正确但缺少支撑不能得高分。** 若某条关键断言在轨迹中找不到对应的调用与返回结果，第2维应大幅扣分，即使最终答案恰好是对的。
- **调用返回空结果等同于没有取得该证据。** 调用存在但没查到任何东西，不能算作证据充分。
- **重复已经做过的调用不能提高分数。** 同一调用重复出现只增加步骤数，不增加信息。
- **步骤说明写得再详尽也不能提高分数。** 只评价实际做了什么与取得了什么，不因叙述篇幅加分。
- **相互独立的步骤换序不应改变分数。** 若两步之间没有数据依赖，先做哪一步不影响这次运行的质量。

## 输出格式

只输出一个 JSON 对象：

```json
{"score": 7.5, "reason": "一句话说明扣分点，指出具体是哪一步缺失或多余。"}
```
