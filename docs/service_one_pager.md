# 7天 LLM 评分器可靠性体检

项目与方法示例：<https://github.com/Potato0705/Agent-Review>

## 适合谁

- 正在开发自动作文评分、文本质量评价或教育反馈系统的团队；
- 已经有模型结果，但不确定指标能否反映真实能力的研究项目；
- 准备投稿、演示、采购或上线，希望提前发现高风险失败模式的团队。

## 我们检查什么

- 无关但流畅的内容是否会错误提高分数；
- 扩大篇幅或堆叠关键词是否能获得奖励；
- 删除核心论点、证据或任务要求后是否明显降分；
- 保持含义不变的表达修改是否造成不合理波动；
- 模型识别内容退化的能力，是否高于它对作弊式修改的奖励。
- 新旧模型或提示词版本是否出现跨阈值回归。

## 客户提供

- 评分标准或任务说明；
- 10条具有代表性的原始样本；
- 模型访问方式，或由客户运行后提供评分结果；
- 当前最担心的错误类型；
- 数据使用与保密要求。

## 7天内交付

1. 20–30条针对性测试；
2. 失败案例与风险等级数据表；
3. 可复现的离线审计结果；
4. 如有旧版本，提供同条件版本回归对比；
5. 一份可直接发送、归档和打印的自包含HTML审计报告；
6. 30分钟线上结果讲解。
