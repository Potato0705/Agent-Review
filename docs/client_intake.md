# 客户需求收集表

## 1. 基本信息

- 团队／项目名称：
- 联系人：
- 联系方式：
- 希望完成日期：
- 是否允许匿名展示案例：是／否／需另行确认

## 2. 系统信息

- 系统名称与版本：
- 系统支持什么业务或研究决策：
- 输入是什么：
- 输出是什么：
- 评分范围：
- 当前使用的模型和提示词版本：
- 当前使用的评测指标：

## 3. 本次审计目标

- 最担心的三类错误：
- 已知失败案例：
- 系统接下来是否要投稿、演示、采购或上线：
- 哪些结论对本项目最重要：

## 4. 数据与访问

- 可提供多少条代表性样本：
- 模型能否通过API或网页访问：
- 是否由客户自行运行测试：
- 数据是否包含个人信息、商业秘密或受限制内容：
- 允许使用的模型／基础设施：
- 数据保存与删除要求：

## 5. 验收范围

基础服务默认包含：

- 最多10条基准样本；
- 20–30条测试变体；
- 一套评分结果；
- 一轮报告修改；
- 一次30分钟讲解。

以下内容需单独报价：大规模Benchmark、人工标注、模型微调、生产部署、持续监测和法律合规认证。
