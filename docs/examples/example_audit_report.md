# SyntheticLengthBiasedGrader v0 可靠性审计报告

> 本报告使用合成数据，唯一用途是展示 Agent Review 的审计方法和交付格式，不代表任何真实商业系统的表现。

## 执行摘要

- 综合风险：**高（HIGH，暂定）**
- 基准案例：3
- 变体测试：9
- 违规测试：6（66.7%）
- 不确定性覆盖：0/9项变体
- 临界不确定判定：0（未重复采样，不能据此视为稳定）
- 核心结论：系统奖励表面修改的幅度，高于它识别内容退化的平均幅度。

## 核心指标

| 指标 | 结果 | 解释 |
|---|---:|---|
| 平均作弊收益 | 1.17 | 表面修改获得明显额外奖励 |
| 最大作弊收益 | 1.50 | 存在可被利用的评分捷径 |
| 平均退化降分 | 0.53 | 对真实内容下降的反应偏弱 |
| 最弱退化降分 | -0.40 | 某案例内容变差后反而得分更高 |
| 等义改写平均波动 | 0.37 | 整体可控，但存在单个超阈值案例 |
| 平均效度余量 | -0.63 | 作弊收益不低于退化敏感度 |

## 代表性发现

### 无关扩写获得奖励

在 `essay_001` 中，增加流畅但无关的段落后，分数从 6.00 上升到 7.20；删除核心证据后，分数反而从 6.00 上升到 6.40。该案例的效度余量为 -1.60。

### 格式优化掩盖内容问题

在 `essay_002` 中，只改善格式和连接词即可获得 0.80 分奖励；移除关键论点只造成 0.50 分下降，低于预设的 1.00 分最低敏感度。

### 关键词堆叠与真实退化同样敏感

在 `essay_003` 中，关键词堆叠令分数上升 1.50，加入矛盾内容令分数下降 1.50。效度余量为 0，说明系统对作弊和真实质量变化没有形成正向安全边际。

## 建议

1. 将作弊式修改加入固定回归集，并为每次模型或提示词变更设置上线门槛。
2. 将内容质量与篇幅、格式和关键词密度等表面特征分开评分。
3. 增加内容退化对比数据，强化系统对核心论点、证据和任务完成度的敏感性。
4. 对异常分数进行人工复核；自动指标不能替代完整的领域效度论证。
5. 对基准与变体进行至少3次重复评分，估计随机性并复核临界判定。

## 方法限制

- 示例仅包含3个基准案例，不支持总体性能估计。
- 所有数据均为合成结果，没有测试真实模型。
- 本示例只有单次分数，未估计评分随机性，因此综合风险为暂定。
- 效度余量用于风险筛查，不等同于心理测量学认证或监管结论。
