# Gemma 3 4B 与 Gemma 4 E4B：同条件评分可靠性对比

> 这是5个手工案例的探索性方法示范，不是Gemma系列排行榜，也不能代表真实教育部署效果。

## 对比设计

两套模型均通过本机Ollama的OpenAI-compatible接口运行，使用完全相同的：

- 5个中文基准短文及15个配对变体；
- 0–10分议论文评分标准；
- 温度0.2；
- 每条输入3次独立评分，共各60次调用；
- 作弊、内容退化和等义改写判定阈值；
- 输入哈希 `79d320b415c64d256112b065f90523dcadb666f0234760d7191a8fff94b4166c`；
- 评分标准哈希 `2f562a3b448ca30adb24025f9f19367cbad42d471ba3f3f849578103868ecc3f`。

对比命令在生成报告前再次校验案例、变体类型、阈值和量表，任一项不同都会拒绝比较。

## 结果

| 指标 | Gemma 3 4B | Gemma 4 E4B | 变化 |
|---|---:|---:|---:|
| 综合风险 | LOW（暂定） | LOW（暂定） | — |
| 违规率 | 20.0% | 0.0% | -20.0个百分点 |
| 临界判定 | 5 | 8 | +3 |
| 平均作弊收益 | -0.53 | -1.32 | -0.79 |
| 平均内容退化降分 | 2.53 | 4.96 | +2.43 |
| 等义改写平均波动 | 0.40 | 0.33 | -0.07 |
| 平均效度余量 | 2.53 | 4.96 | +2.43 |

按均值规则，Gemma 4 E4B没有出现违规，Gemma 3 4B的3项违规均转为跨阈值改善。候选模型对5种内容退化的平均降分更大，也没有奖励作弊式修改。

但这3项跨阈值改善全部涉及至少一侧临界判定，因此都只能写成**暂定改善**。15项逐变体变化中共有10项暂定；Gemma 4 E4B的临界项还从5项增加到8项。最明显的随机性出现在 `remote_work/buzzwords`，三次得分为7.0、6.4和3.3，样本标准差约1.99。

## 可以支持与不能支持的结论

本案例支持：在这5个相同案例上，Gemma 4 E4B的平均退化敏感度更高，按均值计算的违规数更少；工具能够阻止不可比配置，并把不确定改善与稳定改善分开。

本案例不支持：Gemma 4 E4B总体优于Gemma 3 4B、3次重复足以稳定估计随机性、差异具有统计显著性，或任一模型适合真实教育决策。两个模型在本机的推理耗时明显不同，但本案例没有系统测量吞吐，因此不将速度纳入质量结论。

## 复现对比

先按[Gemma 3案例](gemma3_case_study.md)中的方式分别生成两份审计JSON，然后运行：

```powershell
python -m agent_audit compare `
  --reference outputs/gemma3_repeat3_audit.json `
  --candidate outputs/gemma4_repeat3_audit.json `
  --report outputs/gemma3_vs_gemma4_comparison.md `
  --json outputs/gemma3_vs_gemma4_comparison.json
```
