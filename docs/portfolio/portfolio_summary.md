# Agent Review 作品集说明

本文件用于简历、作品集、面试和项目介绍。所有表述都限定在仓库已有证据范围内，不把探索性实验包装成生产级认证。

## 一句话定位

构建了一套面向LLM评分器和AI评测系统的可追溯可靠性审计工具，通过成对干预测试识别表面作弊奖励、内容退化漏检、等义改写不稳定和版本回归。

## 我解决的问题

普通准确率、相关性或单次人工抽查无法回答：评分器是在识别目标质量，还是在奖励篇幅、关键词和表达形式。Agent Review把每个基准样本与三类受控变体配对，并把变化方向、阈值、不确定性和运行上下文保存为可复核证据。

## 已实现能力

- 从CSV离线审计已有评分，输出Markdown、JSON和自包含HTML；
- 调用OpenAI-compatible模型，并严格解析分数、理由和令牌用量；
- 对每条输入重复采样，计算样本标准差、均值差标准误和保守95% t区间；
- 当不确定性未覆盖或区间跨越阈值时，把风险与版本变化标记为暂定；
- 使用输入和评分标准SHA-256、模型、端点、温度、重复次数和量表约束可比性；
- 用逐样本JSONL检查点恢复长任务，并拒绝上下文不匹配、重复键和已终止畸形记录；
- 对HTML不可信内容进行转义，使用限制性CSP且不加载外部脚本或资源；
- 通过本地审查脚本和Python 3.10/3.12 CI执行编译、测试、覆盖率棘轮和离线演示。

## 可核验证据

- 自动化测试：400项，`agent_audit` 行覆盖率99.5%，39个变异体全部被捕获；
- 真实模型示范：5个基准、15个配对变体、每条3次，共60次本地评分；
- 同条件模型对比：Gemma 3 4B与Gemma 4 E4B各60次调用，比较前核对输入、评分标准、温度、重复次数、阈值和量表；
- 故障恢复示范：20条样本全部从检查点恢复，新增模型调用为0，恢复前后评分CSV哈希一致；
- HTML审查：桌面与移动视口检查，发现并修复窄屏表格逐字符换行问题；
- 正确性专项审计：以独立重演公布公式的属性测试发现并修复三处失败打开缺陷（非有限分数、超表范围改用正态近似、布尔值被当作分数），并用15个变异体验证新测试确实能捕获对应缺陷。

这些证据证明工具流程、可追溯性和防误读机制可以工作，不证明任一模型总体优于另一模型，也不证明系统适合真实教育决策。

## 关键工程取舍

1. **先做效度筛查，再做排行榜。** 比较受控变体相对同一基准的变化，避免把不同数据集上的分数直接拼接。
2. **默认失败关闭。** 缺少运行指纹、比较条件不一致或检查点记录异常时直接拒绝继续。
3. **把不确定性写进结论。** 风险仍按透明均值规则计算，但证据不足时必须显示“暂定”。
4. **生成物与源码分离。** 原始回复、检查点和客户报告默认不进入Git，公开示例只使用合成或明确公开的数据。
5. **自动化之外保留人工审查。** 质量门要求逐项检查变体含义、业务影响、结论边界和高风险复现性。

## 面试展开顺序

1. 先解释为什么单一准确率不能发现表面作弊奖励或内容退化漏检；
2. 用 `baseline → gaming/degradation/paraphrase` 说明实验设计；
3. 说明小样本下为什么采用保守t区间并保留暂定结论；
4. 说明比较器如何用双哈希和运行参数阻止不可比结论；
5. 展示一次在视觉审查中发现移动端缺陷并回到实现修复的完整审查闭环；
6. 最后主动说明5个基准案例的限制和下一步需要真实客户数据校准。
