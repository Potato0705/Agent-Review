# Agent Review：90天执行路线图

假设每周可投入5小时，共13周、约65小时。目标是同时增加职业安全感和额外收入，而不是单纯增加代码量。

## 当前执行重点（2026-09-24）

工具已发布至 v0.17.0，并有三篇公开案例、英文说明、客户服务页和可复现的审查门。下一阶段先验证谁确实需要这项审计服务，再依据需求决定新增功能。下表是未来两周的执行目标，不把目标数字当作已经获得的结果。

| 时间 | 行动 | 验收证据 | 投入 |
|---|---|---|---:|
| 第1周 | 核对个人主页上的项目与服务入口；整理10个适配的潜在团队，记录其产品、评分场景和可联系渠道 | 主页可打开的链接；10条有来源的名单 | 2小时 |
| 第1周 | 为其中5个团队各写一条针对其评分场景的简短联系信息，邀请15分钟需求沟通 | 5条已发送记录；不向公开渠道索取私有样本 | 2小时 |
| 第1周 | 整理公开案例的一页讲解：删掉证据步骤、评分不降、另一种退化却降分，以及5条合成轨迹的限制 | 一份可在15分钟内讲完的演示 | 1小时 |
| 第2周 | 跟进已联系对象，再联系5个适配团队 | 累计10条定向联系；回复和拒绝原因逐条记录 | 2小时 |
| 第2周 | 完成最多2次需求沟通；只对明确适配的团队提供3条非敏感样本的小范围诊断 | 沟通记录、问题优先级、是否愿意付费试点 | 2小时 |
| 第2周 | 复盘沟通与交付耗时，决定继续当前服务范围、调整目标客户，还是改为更小的实验设计诊断 | 一页复盘，包含联系数、回复数、沟通数、报价数和订单数 | 1小时 |

任何真实客户的样本、授权、模型供应商和数据删除要求，均在私密渠道确认后再开始测试。没有得到客户反馈之前，不把新的代码功能当作这一阶段的完成标准。

## 90天结果目标

| 指标 | 目标 |
|---|---:|
| 公开工具 | 1个可复现仓库 |
| 公开案例 | 2篇 |
| 定向联系人 | 40–50人 |
| 有效需求交流 | 5–10次 |
| 付费客户 | 3–5个 |
| 客户评价 | 至少2个 |
| 定向岗位申请 | 10–15个 |
| 累计额外收入 | 5,000–12,000元 |

## 第1–2周：完成最小产品

### 第1周

- [x] 建立Python审计工具；
- [x] 提供合成评分数据；
- [x] 自动生成Markdown和JSON结果；
- [x] 建立服务说明、客户表单和报告模板；
- [x] 在GitHub发布首个版本。

### 第2周

- [x] 用本地Ollama模型和公开示范文本完成真实评分；
- [x] 增加到5个基准案例和15个变体；
- [x] 写成不超过800字的公开案例；
- [x] 增加重复采样、保守区间与暂定风险标记；
- [ ] 将服务链接加入个人主页。

每周时间：3小时案例与工具，1小时文档，1小时对外展示。

## 第3–4周：首次触达

### 第3周

- [ ] 列出10个实验室、教育AI团队和熟人联系人；
- [ ] 给前5人发送个性化信息；
- [ ] 只提供3条免费诊断，不免费完成全部项目；
- [ ] 记录对方最关心的风险类型。

### 第4周

- [ ] 再联系5–10人；
- [ ] 完成至少2次15分钟需求沟通；
- [ ] 成交首个999元试点，或两个399元实验设计诊断；
- [ ] 根据反馈修改服务说明。

每周时间：2小时触达，2小时沟通或演示，1小时改进材料。

## 第5–6周：完成首个付费交付

### 第5周

- [ ] 使用客户需求表锁定范围；
- [ ] 设计20–30条测试；
- [ ] 运行评分并生成报告；
- [ ] 人工复核所有高风险结论。

### 第6周

- [ ] 完成30分钟结果讲解；
- [ ] 获得一句客户评价；
- [ ] 请求一个转介绍；
- [ ] 在获得许可后制作匿名案例。

有交付的星期：4小时交付，30分钟评价与转介绍，30分钟管道维护。

## 第7–9周：形成复用资产

### 第7周

- [ ] 将真实反馈加入README和服务说明；
- [ ] 将首批试点价提高到1,499元。

### 第8周

- [ ] 成交第二个审计或两个实验设计诊断；
- [x] 将重复步骤自动化（`generate` 子命令由带标注基准生成作弊与退化变体，v0.10.0）。

### 第9周

- [x] 增加英文项目入口、公开HTML示例和隐私安全的需求入口；
- [x] 将最新版本发布到GitHub。

## 第10–11周：转化为求职资产

### 第10周

- [x] 准备评测方向的中英文简历与面试表述；
- [ ] 将CVM、EJRD、Agent Review和客户案例排在前四项；
- [x] 为项目增加英文说明和英文简历表述；

### 第11周

- [ ] 申请5个LLM/Agent评测、可信AI或Benchmark岗位；
- [ ] 联系3位相关从业者；
- [ ] 请求一次作品集反馈；
- [ ] 记录岗位反复要求但自己缺少的技能。

## 第12–13周：建立复购与复盘

### 第12周

- [ ] 向已有客户提供月度回归测试；
- [ ] 服务范围为每月20条新测试、一次版本复测和一次复盘；
- [ ] 起步价格999–1,999元/月。

### 第13周

- [ ] 汇总触达、成交、收入和岗位反馈；
- [ ] 判断下一季度主攻服务、求职还是二者并行；
- [ ] 删除无人需要的功能；
- [ ] 只在客户反馈明确重复需求后，选择下一项功能并确定版本范围。

## 调整条件

- 联系30个高度匹配对象仍没有一次沟通：修改目标客户或首句话术；
- 完成5次沟通仍没有付费：缩小服务范围、增强示范证据，而不是继续免费工作；
- 每单交付超过4小时：减少样本、限制修改轮次或提高报价；
- 第45天仍没有客户：用399元实验设计诊断建立现金流，同时保留评测工具作为求职资产；
- 岗位反馈集中要求工程能力：下一版本优先增加API、数据库和可视化，不再扩展研究指标。
