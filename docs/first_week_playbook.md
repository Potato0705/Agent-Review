# 首周执行清单

目标：在7天内形成一个可展示案例，并接触至少5个潜在客户。

## 第1天：确认服务

- [ ] 检查 `docs/service_one_pager.md` 的范围和价格；
- [ ] 将项目链接加入个人主页；
- [ ] 准备联系邮箱或预约方式。

## 第2–3天：完成公开案例

- [ ] 使用 `examples/demo_scores.csv` 运行演示；
- [ ] 阅读 `outputs/demo_report.md`；
- [ ] 将合成案例改写成一篇不超过800字的公开说明；
- [ ] 明确标注示例为合成数据。

## 第4天：准备交付

- [ ] 复制 `docs/client_intake.md` 建立客户表单；
- [ ] 检查报告模板；
- [ ] 确认客户数据不会进入未经授权的公共模型。

## 第5天：列出10个联系人

- [ ] 3个研究或实验室联系人；
- [ ] 3个教育科技或AI团队；
- [ ] 2个竞赛或校友联系人；
- [ ] 2个开发RAG或文本评价产品的团队。

## 第6–7天：发送首批消息

推荐话术：

> 我最近把LLM评分有效性方面的研究整理成了一个固定范围的可靠性体检，主要检查无关内容、篇幅、提示词和表面修改是否会错误影响评分。目前寻找两个首批案例。我可以先免费检查3条样本，确认是否存在值得进一步审计的问题；完整审计包含20–30条测试、风险报告和结果讲解，首批价格999元。方法示例：https://github.com/Potato0705/Agent-Review

成功标准：

- [ ] 至少发送5条个性化信息；
- [ ] 获得至少1次有效交流；
- [ ] 记录对方拒绝或犹豫的原因；
- [ ] 不免费完成完整审计。
